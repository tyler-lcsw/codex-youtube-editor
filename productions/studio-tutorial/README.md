# Codex Media Studio illustrated tutorial

A 5:38, text-led quick-start tutorial based on the current user guide. Twelve chapters follow an example desk-setup edit through intake, source/reference roles, resource preferences, desktop Codex handoff, understanding, revision review, feedback, correction, QA and help.

The user reports that in-app authentication remains unresolved. The tutorial therefore teaches **Export handoff → desktop subscription Codex**, without claiming the in-app session works. It is explicitly labeled an **illustrated workflow**, not a recording of a successful raw-footage edit.

## Production sources

- `scenes.json`: editable chapter copy, durations and illustrative examples.
- `StudioTutorial.tsx`: deterministic Remotion composition with the app's ivory/coral/graphite identity and repository-vendored licensed fonts.
- `render.py`: single-worker, network-denied Remotion render; restrained procedural pop cues; staged H.264/AAC export. Run media actions through the existing production-quality coordinator.
- `verify.py`: decode, dimensions/frame count/duration, exact cue-stem timing, loudness/true peak and final chapter-frame extraction. Technical review is not continuous audiovisual acceptance.

No narration, cloned voice, hosted images, external reference media, music-generation model, avatar, diffusion-video model or publication service was used. The absence of narration is intentional: all teaching content is readable on screen, with time based on about 175 words per minute plus entrance allowance.

The durable Studio project and local media live outside Git in `~/Movies/Codex Studio/Studio Tutorial September 6`. The source guide is imported as a document, project context is exported to a real Codex handoff, and rendered revisions preserve separate attempt folders. Media and project state are not committed.
