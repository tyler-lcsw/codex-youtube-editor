# First Release — Completion and Deferred Work

This closes the approved single-M4 implementation scope and its immediate compatibility/recovery follow-ups. It does not reopen the superseded example-video benchmark.

Completed: Codex-native skills, Mac/CPU encoders, pinned local ASR/alignment/cleanup/TTS/images, one-node PAIR MLX trials, retained Remotion with local fonts, derived edit timing and independent render ASR, local tracker, scoped native image handoff, guarded legacy hosted commands, repeatable setup and upstream audit, timeline validation/effects, failure-preserving exports, and bounded Astra/Sol acceptance tooling.

Evidence is in `docs/benchmarks/first-release.md`, `docs/benchmarks/acceptance.md` and `docs/timeline-compatibility.md`. The test suite excludes the publication test by explicit user instruction. No hosted media or YouTube upload was performed. Local jobs remain within the single-M4 profile; other machines were not configured.

Deferred under the revised scope: large/multi-reference image qualification, avatar/video models, generative music/SFX, multi-node scaling, long-context qualification, personal likeness/voice and long-form creative parity. Full automation of every legacy command through one cache/scheduler is not claimed. These are recorded in `docs/known-limits.md`, not marked complete by passing synthetic tests.

The next production work is an actual owner-selected video with supplied footage, brand decisions and any intended voice/face references. Those inputs are not inferred from upstream assets. Automatic development/PR merging remains authorized, while hosted generation still requires scoped approval and publication remains a separate explicit decision.
