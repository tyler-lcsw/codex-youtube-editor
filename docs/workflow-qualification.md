# Existing-video workflow qualification contract

This is the authoritative contract for claiming that the reusable supplied-footage
workflow is qualified. It is separate from the per-production checklist in
[production rules](production-rules.md). It carries forward former R30; moving it
does not waive the qualification requirement or establish that it has passed.

## Required demonstration

Do not call the existing-video workflow qualified until it passes a representative
real-footage edit containing authentic speech, meaningful editorial cuts, visible
synchronization, selective graphics, and complete normal-speed audiovisual review.
Use relevant graphics for this qualification exercise; ordinary productions need not
include graphics solely to demonstrate capability.

The qualification production must itself satisfy the current production quality
workflow. Synthetic fixtures, an installed provider, a successful render, or the
generated Lighthouse exercise cannot substitute for authentic-footage evidence.

## Evidence and scope

Record the source and output revisions, engine/provider versions, tested operations,
technical checks, visual and listening findings, unresolved limits, and the current
production completion receipt in a qualification report. Record owner acceptance
separately; never infer it. Unavailable required reviews leave qualification pending.

Any qualification claim must identify the tested scope and its report. Material changes
to that scope, pipeline, providers, or applicable policy require an impact review and
revalidation of affected evidence before carrying the claim forward. Do not run a new
qualification exercise for every ordinary production merely because former R30 existed.

Conversely, historical workflow qualification is never acceptance of another production.
Every production still needs its own current before/during/after evidence and completion
receipt. Qualification does not authorize publication, hosted generation, downloads,
or expansion beyond the approved runtime scope.

## Enforcement boundary

The quality coordinator enforces production-rule coverage and evidence freshness, not
this separate workflow-level qualification claim. The responsible AI/reviewer must check
the qualification report before claiming the reusable workflow is qualified. This move
does not implement a new automated qualification registry or certify previous outputs.
